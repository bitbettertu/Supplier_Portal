# ЛКП — Личный кабинет поставщика (MVP: контур поставщика)

Веб-макет внешнего контура единой платформы **MDM 2.0** (UMAI GROUP, ОПСУ).
Реализует **только** сценарий поставщика: вход → ведение своего ассортимента →
ввод базовых мастер-данных карточки → отправка заявки на ввод в 1С → отслеживание статусов.

Источник требований: **ТЗ MDM 2.0 v0.2** (§4.2–4.3, ВИ 3.3.2/3.3.3, §5.3, §6.1).

## Что в скоупе (активно)

- **Вход** — логин/пароль + опциональный код на почту (ВИ 3.3.2). Открытой регистрации нет: аккаунт заводит сотрудник UMAI.
- **Мои товары** — список ассортимента поставщика со статусами заявок, фильтры и поиск.
- **Карточка товара** — блок поставщика (§4.3 Блок 1 + ВИ 3.3.3):
  наименование `ru`/`kg` (двуязычие на уровне атрибута), бренд (справочник),
  товарная марка, штрихкод (валидация EAN‑8/13 по контрольной цифре),
  вес нетто, код ТНВЭД, страна происхождения.
- **Код товара (1С)** — read‑only: присваивается 1С обратным потоком после публикации (§5.3).
- **Статусы**: Черновик → Принята → В работе → На доработке (возврат ОМД с причиной) → Опубликовано в 1С.

## Что намеренно заблокировано (видно, но с замком)

Граница владения данными из ТЗ (§2.4.1): операционные данные — домен 1С, вне MDM.

- Разделы меню: **Переоценка** (Фаза 2, мимо MDM), **Акции**, **Документы·АВР** (система «Питон»), **Аналитика**.
- Вкладки карточки, принадлежащие внутренним отделам: **Тип/регуляторика** (КО·Импорт),
  **ВГХ·упаковки** (РЦ), **Хранение·контент** (УЦП), **Цены·переоценка** (1С).

> Это макет: данные хранятся в памяти (seed), бэкенда и реальной интеграции с 1С/MDM нет.

## Стек

React 19 · TypeScript · Vite · Tailwind CSS 3 · shadcn/ui (Radix) · lucide-react.

## Запуск

```bash
pnpm install      # или npm install / yarn
pnpm dev          # дев-сервер (http://localhost:5173)
pnpm build        # прод-сборка в dist/
pnpm preview      # предпросмотр прод-сборки
```

Демо-вход: логин подставлен, пароль — любой.

## Структура

```
src/
  App.tsx              # экраны: вход, портал, список товаров, карточка, заблокированные разделы
  lib/lkp-data.ts      # модель данных, справочники, статусы, валидация (штрихкод/ТНВЭД/вес)
  components/ui/        # компоненты shadcn/ui
  index.css            # тема: navy #1F3864 + teal accent
```
